7. Why did you choose pagination instead of infinite scrolling?
=> 
    Since the application is a structured dashboard handling large tabular datasets, server-side pagination provides more predictable memory usage, better navigation, and easier backend query control compared to infinite scrolling.


8. MongoDB is sorting : As text/string || NOT : numbers

    comes BEFORE: "Project 2"
    because : "1" < "2" lexicographically.

9. Why can schema updates fail to appear in MongoDB?
=> 
    MongoDB is schema-flexible, so existing documents are not automatically updated when application models change. Data reseeding or migrations are required to introduce new fields into old documents.
