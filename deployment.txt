** Interview  **

1. Why do deployed apps use process.env.PORT instead of hardcoded ports?
=> 
    Cloud platforms dynamically assign ports to deployed applications, so applications must bind to the runtime-provided environment port instead of fixed local ports.

2. Why is CORS required in full-stack deployments?
=> 
    Browsers block cross-origin requests by default for security reasons, so CORS must explicitly allow frontend and backend communication across different domains.

3. Why avoid granting access to all repositories for third-party services?
=> 
    Limiting repository access reduces security exposure and follows the principle of least privilege, ensuring services only access resources they actually require.

4. Why choose deployment region carefully?
=> 
    Choosing a region close to the primary user base reduces network latency and improves response times and overall user experience.
